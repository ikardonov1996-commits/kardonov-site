# 3D: мраморный Давид, глыба, ворот

Рендеры и исходные скрипты Blender 4.2 для блока «Придаём форму вашим задачам» и сцены со спуском глыбы.
Тяжёлые .blend-файлы (30–60 МБ) в репозиторий не кладём — они пересобираются скриптами из `scripts/`.

## renders/stages — обтёсывание глыбы (5 кадров)

WebP 1080×1440, прозрачный фон, одна неподвижная камера (3/4) — кадры ложатся друг на друга без сдвига.

1. `stage_1_Marble_Block` — глыба
2. `stage_2_C4_Freed` — гранёная фигура выходит из толстого остатка блока (рубленые края, канавка, грубый постамент)
3. `stage_3_C5_Point` — грубая гранёная фигура (шпунт)
4. `stage_4_C6_Claw` — уточнённые плоскости (скарпель)
5. `stage_5_Sculpture_HiRes` — полированная статуя

## renders/windlass — глыба на вороте (слои для скролла)

Все слои вырезаны из одного холста (`layers.json`: `canvas`, `layers.<имя>` = x/y/w/h в пикселях холста).

Порядок снизу вверх:

1. `windlass_back_NN` — задняя половина ворота
2. `block_rope` — глыба в обвязке с длинной верёвкой, нарисована в нижнем положении
3. `windlass_front_NN` — передняя половина ворота

- Спуск: `translateY = -(1 - descent) * drop_total_px`, `descent` 0→1 по скроллу.
- Верёвку выше линии барабана скрыть: `clip_block_layer_above_y_px`.
- Весь металл ворота (рычаг, ступица, кольца, ось, обода барабана) — тот же светлый титан, ручка деревянная.
- Ворот: 12 кадров = 1 оборот рукоятки (`NN` 00–11), за весь спуск ≈ 4,5 оборота.
- Качание: поворот слоя глыбы вокруг `pivot_px` на 1,5–3°, затухающий маятник (`swing` в json).

## renders/tools — молот и долото

Свет как у Hero: тёплый ключ шампань, глубокие тени, тонкий голубой контровой. Cycles, прозрачный фон.

- `hammer_site`, `chisel_site` — 1600×1600, ракурс 3/4.
- `hammer_profile` (718×1600), `chisel_profile` (364×1600) — строгий профиль для анимации удара; `profiles.json` — точки (ударные грани, торец рукояти, боёк и острие долота) в px и `px_per_m` для масштаба.
- `*_glow` — слои свечения: RGB = брендовый цвет (#77D9FF долото, #FCCB84 молот), alpha = интенсивность; класть поверх (`mix-blend-mode: screen`).
- Молот = человек (мрамор, золото, кремовая кожа, свечение шампань), долото = ИИ (светлый титан `scripts/mat_ai_titanium.py`, стальное лезвие, голубой неон).
- Скрипты: `scripts/tlight/` (рендер, склейка полос, постобработка).

## scripts

Пересборка: `blender -b <file>.blend -P scripts/<script>.py -- <args>`. Основные:

| Скрипт | Что делает |
|---|---|
| `marble2.py` | процедурный мрамор |
| `fix_anatomy2.py`, `remesh.py`, `decimate.py` | правка анатомии и подготовка сетки статуи |
| `block2.py` | глыба |
| `make_assets.py` | ассеты статуи / глыбы |
| `stages2.py` | этапы обтёсывания |
| `c4free/build_freed.py` | этап «фигура в камне» v2 |
| `carve_rig.py`, `render_stills.py` | переходы и финальные кадры этапов |
| `rope_build.py` | сцена с воротом |
| `site_layers.py`, `site_composite.py` | слои для сайта и их проверка |
| `c2`…`c9/build*.py` | роборука и нейроинтерфейс v2–v9 (v9: светлый титан, неон-индикаторы, кисть по руке Давида) |
